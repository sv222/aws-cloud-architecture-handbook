# Contributing

Thanks for helping improve this handbook. It is a practical guide to designing and running systems on AWS, written for engineers who do that work.

## How to contribute

1. Open an issue to discuss a larger change, or send a pull request for a small fix.
2. Keep edits small and factual. One topic per pull request is easiest to review.
3. Cite an official AWS source (docs.aws.amazon.com or aws.amazon.com) for any new fact, service limit, or changed quota.
4. Follow the existing Markdown style and heading levels.
5. When you add a section, update the table of contents in `README.md`.
6. Run the link check locally before you push:

   ```bash
   lychee --include-fragments README.md
   ```
